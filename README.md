## 탭 구성
1. **🎄 파티 안내** — 일시·장소(카카오/네이버/티맵 길찾기) · 공지사항(여러 개·개별 삭제·계좌번호/송금 링크 버튼) · 일정표 · 장보기(실시간, 살 것·수량·단위·분류·담당/메모, ✏️ 인라인 수정) · 참가자(닉네임 (이름) + 5글자 각오)
2. **🎮 게임 안내** — 메인 5게임 + 보너스 2게임 규칙 · 팀/조 명단 · 준비물 체크 · 게임 순서에서 카드로 바로 이동 · 🎬 예시 영상 링크(가면 그릇치기·종이컵 왈츠·사진피하기·인아웃 점프)
3. **🏆 점수판** — 실시간 TOP3 · 시상식 폭죽 · 비밀 경품 · 점수 입력(관리자 잠금)
4. **🎡 룰렛** — 할리갈리 5모드 룰렛 · 원터치 타이머 · 만능 MC 도구(뽑기/순서/조섞기/초성)
5. **💌 방명록** — 한 줄 방명록(빠른 문구 칩 · 엽서 카드 · 📷 사진 1장 · ❤️ 좋아요 · 본인/관리자 삭제, 실시간) · 관리자 `🙈 숨기기/💌 열기` 토글(숨기면 참가자는 4탭)

방명록 탭 하단에는 `🎅 수고하셨습니다! 메리 크리스마스 🎄` 푸터가 있어요. 관리자는 '파티 안내 > 공지사항' 아래 `🙈 방명록 숨기기 / 💌 방명록 열기` 버튼으로 방명록 탭을 잠시 숨길 수 있어요(숨기면 참가자 폰에는 4탭만 보이고, 다시 열면 실시간으로 5탭이 됩니다).

## 같이 쓰는 법
- 링크를 각자 폰으로 열고, **내 프로필**에서 본인을 고른 뒤 닉네임·사진을 정해요.
- 점수·공지·장보기·룰렛 결과·프로필·방명록은 **실시간으로 모든 폰에 동기화**돼요 (Firebase Realtime DB, AES-GCM 암호화).
- 연결 상태는 상단 제목 아래 점으로 확인할 수 있어요.
